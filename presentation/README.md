# 安脉 Agent 赛事答辩材料

- 正式 PPT：[安脉-Agent-赛事答辩-v3.pptx](output/安脉-Agent-赛事答辩-v3.pptx)
- 可编辑源脚本：[create-deck.mjs](build/create-deck.mjs)
- 界面截图位于 `assets/`，来自本地模拟原型；模型复核截图使用 Fake Provider。

PPT 共 17 页、16:9、无学校与个人姓名。它说明当前已完成的模拟流程、Agent 主循环、三种模型任务、分层风险证据、产品价值和未来路线。公开数据仍处于选型阶段，尚未接入演示原型，也未用于临床性能验证。

赛事材料要求另行提交不超过 6 分钟的 MP4 视频和评委可访问的智能体链接。当前 Railway 服务为节省额度已暂停，比赛演示前需要恢复部署，并将评委访问凭证通过官方提交渠道提供。不要把 DeepSeek API Key 写入 PPT 或仓库。

制作依据：[主设计方案](../docs/安脉-Agent-设计方案.md)、[风险证据方案](../docs/superpowers/specs/2026-11-09-risk-evidence-design.md)、[公开数据选型](../docs/research/open-health-data-2026-11-09.md)。
