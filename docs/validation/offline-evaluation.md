# 异常规则离线评估接口

当前**没有**目标人群中经过临床裁定的事件标签，因此还不能报告安脉对心梗、卒中或猝死风险的灵敏度、特异度和误报率。`eval:windows` 只为未来合法取得的去标识化、已标注数据准备评估入口；不会修改线上规则或阈值。

运行方式：`pnpm eval:windows <本地 JSON 文件>`。输入是数组，每项包含唯一 `id`、`reference`（`event`、`no_event` 或 `unlabelled`）、非空 `samples`（与 `/api/ingest` 的体征格式相同），可选 `baseline`。一个条目代表一个已定义的时间窗口；标签应由独立于本算法的临床标注流程确定。工具不发送数据到模型，也不保存输入，只输出窗口 ID、规则等级和汇总计数。不要把姓名、精确位置或其他直接身份信息放入文件。

输出的“阳性”是规则返回 `abnormal` 或 `worsening`，仅衡量**规则层的窗口级结果**，不代表完整的 Agent 响应、诊断或救治效果。`unlabelled` 窗口照常运行规则，但不进入灵敏度、特异度分母。没有阳性或阴性标签时，对应指标为 `null`；数据不可信时若未发出告警，会计为有事件窗口的漏报，或无事件窗口的未告警，需同时检查质量排除情况。未来正式验证还需要按受试者划分训练/验证/测试集，定义事件与非事件窗口、标签一致性、误报次数/人日和响应时延，并由临床团队审查。

BIDMC 单记录只有床旁监护数值，没有心梗、卒中或居家恶化裁定标签；若用它试运行工具，应标为 `unlabelled`，不得把演示规则结果当作临床真值。[BIDMC 官方说明](https://physionet.org/content/bidmc/1.0.0/)
